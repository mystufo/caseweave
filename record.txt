  PATCH  /api/sessions/{id}         会话重命名
  GET    /api/sessions/{id}/messages 会话消息历史
  GET    /api/sessions/{id}/clarification_state 会话澄清状态（刷新回放）

  — 上传 / 澄清 / 生成 —
  POST   /api/upload                上传文档（返回解析结果 + 澄清问题）
  POST   /api/upload/stream         上传 PRD（SSE：解析 / 知识预览 / 自动分类）
  POST   /api/upload/mindmap/stream 上传测试脑图（SSE，Markdown outline）
  POST   /api/upload/lark/stream    飞书文档导入（SSE，调用 lark-cli）
  POST   /api/clarify/initial/stream 首轮澄清（SSE，PRD/脑图至少一份）
  POST   /api/clarify/followup/stream 续答澄清（SSE）
  POST   /api/generate              生成测试用例（PRD + 脑图双输入）

  — 用例 / 导出 —
  GET    /api/cases                 用例列表（跨会话浏览）
  GET    /api/sessions/{id}/cases   指定会话用例
  DELETE /api/cases/{id}            删除用例
  POST   /api/export/cases          按勾选的用例 ID 导出 Excel
  GET    /api/export/{session_id}   导出会话全部用例 Excel

  — 反馈 —
  POST   /api/feedback              提交反馈（like / dislike / edit；edit 异步触发 diff 分析）
  GET    /api/feedback/recent       最近 N 条已分析的 edit 反馈（intent + summary）

  — 模块 / 知识库 —
  GET    /api/modules               模块列表（含 code 英文名）
  POST   /api/modules               新建模块（可带 code 英文名 = 用例编号前缀）
  PUT    /api/modules/{id}          改模块中文名 / 英文名 code / 描述
  DELETE /api/modules/{id}          删除模块（名下资产变未分类，不级联删）
  GET    /api/module_relations      模块关联关系列表
  POST   /api/module_relations      新建关联
  DELETE /api/module_relations/{id} 删除关联
  GET    /api/documents             文档列表（module_id / only_orphan / role 过滤）
  GET    /api/documents/{id}        文档详情（含截断正文，只读预览）
  PATCH  /api/documents/{id}        改文档归属模块（module_id=null 取消归属）
  GET    /api/knowledge/preview     知识预览
  GET    /api/knowledge/stats       知识库总览（总条目 / 类型 / 模块覆盖 / 近 N 天新增）
  GET    /api/knowledge             知识条目列表
  GET    /api/knowledge/{module_id} 指定模块知识条目
  PUT    /api/knowledge/{id}        更新知识条目
  DELETE /api/knowledge/{id}        删除知识条目
  GET    /api/documents/{id}/pending_knowledge          文档待审核知识草稿
  POST   /api/documents/{id}/confirm_pending_knowledge  确认草稿入库

  — Skill（测试设计经验）—
  GET    /api/skills                技能列表
  GET    /api/skills/{id}           Skill 详情（含 content）
  POST   /api/skills                新建 Skill（人工）
  PUT    /api/skills/{id}           更新 Skill（content 改变时 version 自增）
  DELETE /api/skills/{id}           删除 Skill
  POST   /api/skills/regenerate     按模块自动归纳 Skill（LLM）

  — System Prompt 版本化（Phase 4.2，项目隔离）—
  GET    /api/prompts                      可管理提示词列表 + 生效概览
  GET    /api/prompts/{key}/default        取原始建议版本（代码默认）
  GET    /api/prompts/{key}/versions       历史版本列表
  POST   /api/prompts/{key}/versions       保存为新版本（activate 可同时设为生效）
  POST   /api/prompts/{key}/versions/{id}/activate  切换生效版本
  POST   /api/prompts/{key}/reset          恢复使用原始建议版本

  GET    /health                    健康检查
